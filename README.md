# balatro-terminal
Esse repositório serve pro jogo Balatro no Terminal (CMD) em python

O Github é um site que utiliza a tecnologia Git e deixa ela mais fácil de ser usada. O Github é muito utilizada pra criação de projetos porque ela permite que você faça alterações, compartilhe repositórios e ideias, divida tarefas, tenha histórico, etc. Ou seja, dá pra fazer tudo e com sabedoria, você pode retornar aonde não estava dando problema no projeto. Portanto, a gente vai utilizar ele pra fazer o projeto pra não ter que ficar enviando arquivos toda hora.

Tutorial de como instalar o projeto no PC:

1. Instale o Git
  - Windows: baixe em git-scm.com/downloads, execute o instalador e clique em Next até o fim.
  - Confirme que instalou: git --version

2. Copie o link do repositório
  - Abra o repositório no GitHub.
  - Clique no botão verde Code.
  - Na aba HTTPS, copie a URL (https://github.com/pzgfps/balatro-terminal.git).

3. Clonar o projeto
  - Abra a pasta onde você quer clonar o projeto, de preferência uma pasta da área de trabalho criada só pro projeto
  - Clique com o botão direito e vá em "Abrir no terminal"
  - Vai ser criada uma pasta com o mesmo nome do repositório "balatro-terminal"
  - No terminal ainda, use:   cd balatro-terminal
  - No terminal novamente use:   code .      (tem que ter o ponto final)

4. Autenticação
   - Quando você for "subir" mudanças no projeto, o Git provavelmente vai pedir suas credenciais, dai você pede ajuda pra nois
